# Super Ontology S1 license copies (B-S1-07)

Exact bytes of every `LICENSE*`, `COPYING` and `NOTICE` file found in the crates.io `.crate` tarball of each package recorded by `supply-chain/{blake3,pulldown-cmark,calamine,opendal,proptest,unicode-normalization}-audit.json`, one directory per `name-version`. Each tarball was downloaded from static.crates.io into an empty directory, its SHA-256 compared with the `Cargo.lock` checksum (all matched), and treated as data: nothing was built or run from it. The `sha256` of each file is in the record that cites it.

Renames made on copy so the file name fits the policy locator shape (policy section 2): in `blake3-1.8.7`, upstream `LICENSE_A2` is `LICENSE-Apache-2.0`, `LICENSE_A2LLVM` is `LICENSE-Apache-2.0-WITH-LLVM-exception`, `LICENSE_CC0` is `LICENSE-CC0`. Bytes are unchanged. `unicode-normalization-0.1.25/COPYRIGHT` is kept as supporting text and is not cited as license evidence.
