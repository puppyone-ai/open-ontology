| Method | The list is the package set found in `app.asar` of a real `electron-builder --mac dir --arm64` pack of this tree (2026-11-19, output outside the repository), cross-checked against the runtime dependency walk of each direct package. | Gap in the generated notice | `THIRD_PARTY_NOTICES.md` is generated by `pnpm licenses list --prod` for the app importer.
