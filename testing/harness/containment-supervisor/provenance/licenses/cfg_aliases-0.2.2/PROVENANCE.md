# cfg_aliases 0.2.2 notice locator

The crate ships `NOTICES.md`. That basename is not a `LICENSE` or `NOTICE` locator under `governance/qa_license.py`. This directory keeps the upstream bytes under the original name `NOTICES.md`.

`NOTICE` is a byte-identical copy of that same `NOTICES.md`. It is the locator an audit record can name.
