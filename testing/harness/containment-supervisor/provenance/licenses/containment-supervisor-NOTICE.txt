Separate obligations
--------------------

Dependencies, native code, container images, fonts, upstream runtimes, and
datasets carry their own licenses and notices. Those obligations are not
settled by this file.

Unverified components stay unverified. docs/02-technology-stack.md section 5
is a selection-time license boundary for the default install. That section
states that it is not a finished transitive audit. This NOTICE does not
convert that boundary into one.

In particular, nothing here audits or clears:

- Cargo, npm, and other package dependencies, including transitive ones
- Native code compiled or vendored into a build (including libpg_query,
  embedded PostgreSQL sources, DuckDB, and code executed by build.rs)
- Container base images, OS packages, fonts, and offline extensions
- Upstream products used beside this repository (PostgreSQL, Valkey,
  Debezium, gVisor, Pi, and the other products named in
  docs/02-technology-stack.md)
- Benchmarks, gold labels, generated datasets, and customer data
- Optional external services kept out of the default image (the design names
  Grafana, Redis 8, MinIO, and Vault in this category)

No SPDX SBOM exists for a distributable artifact. supply-chain/dependency-baseline.json
is a later foundation record. It is not created by this NOTICE. A per-artifact
NOTICE, listing only the third-party notices actually verified for that
digest, is required with the first M1 artifact. That artifact does not exist.
