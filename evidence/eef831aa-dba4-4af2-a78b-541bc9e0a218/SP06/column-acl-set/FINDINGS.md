A logical column `_oo_pos`, or a logical name that starts with `_oo_`, is `MetadataColumn`. `compile_column_acl` still accepts a logical column named `_oo_pos`. The unit test `a_set_refuses_empty_mixed_duplicate_bounds_and_metadata` passed on the pinned image. The live oracle records `pure_refusals=empty_duplicate_mixed_filter_metadata` and `refusal_roles=unchanged`.
