Inventory uses evidence tools/sha256.rs, the a227 byte-identical copy, git hash-object b69a2af13099ce4baf2d04e79c5692d9988ab67d.

The command inside the container is:

rustc --edition 2021 /tools/sha256.rs -o /work/sha256
/work/sha256 dir /evidence/SHA256SUMS /evidence

Cleanup runs first. CLEANUP.txt is in the tree before either inventory container. The inventory containers do not use the cargo or target volumes.

oo-a234-hash writes the first manifest, then the launch script stores hostconfig.txt, mounts.txt, docker-run.exit, and container-removed.txt. Those four files are absent from the first manifest.

oo-a234-hash2 is --rm and rewrites SHA256SUMS after those files exist. Its inspect is not stored. No evidence file is added after that rewrite. SHA256SUMS and SHA256SUMS.sha256 are skipped by the tool and are the manifest itself.
